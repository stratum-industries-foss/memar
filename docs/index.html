Key Features

Everything you need to manage equipment fleets at scale

📊

OEE Metrics

Availability × Performance × Quality. Real-time insights into equipment efficiency. Identify bottlenecks instantly.

📐

Interactive Floor Plan

Drag-drop device positioning with live status visualization. See your entire operation at a glance. Manual or agentic layout.

🔔

Event Webhooks

Real-time event dispatch: `printer.error`, `printer.complete`, `printer.offline`. React instantly to failures.

🔐

Role-Based Access

Admin, operator, viewer roles. JWT auth with encrypted offline licensing. Multi-user management built-in.

🔌

Multi-Protocol

Klipper, Bambu Labs, Prusa, GRBL, OPC-UA, MQTT, and generic REST adapters. Connect anything.

🏗️

Extensible Architecture

Build custom adapters for proprietary equipment. Adapter ecosystem for any REST API or MQTT source.

Get Started

Self-host MEMAR locally in under 5 minutes with Docker Compose.

COPY
$ git clone https://github.com/stratum-industries-foss/memar.git
$ cd memar
$ docker-compose up -d

# Dashboard at http://localhost:8000
# Login with 'admin' / password in logs

Full documentation: Check the GitHub README for adapters, API docs, and production deployment.
