## What's Included

### 🔌 **18 Machine Adapters** — 6 supported, 12 alpha

> **Status:** the six adapters below are supported. Bambu Lab (reverse-engineered, unverified against live hardware) and the eleven CNC/industrial adapters are **alpha**. In particular, **Haas, Fanuc, Fadal, and Mach4 are unverified against real hardware — emergency-stop is not guaranteed**; treat CNC control as pilot/roadmap and validate on your machines before production use.

**Supported:**
- Klipper/Moonraker (primary)
- OctoPrint
- Duet 3
- Prusa Connect
- Marlin
- FluidNC (ESP32 CNC/laser controller)

**3D Printing (alpha):**
- Bambu Lab (reverse-engineered API)

**CNC / Subtractive (alpha — ⚠️ Haas/Fanuc/Fadal/Mach4 unverified against real hardware, e-stop not guaranteed):**
- GRBL (hobby/desktop mills)
- LinuxCNC (full-featured)
- Mach3 / Mach4 (Windows-based)
- Sinumerik (industrial)
- Haas (legacy machines)
- Fanuc (robotics integration)
- Fadal (VMC control)

**Cross-Cutting (alpha):**
- OPC-UA (industrial IoT)
- MQTT (pub-sub telemetry)
- OpenPCB / OpenPnP (pick-and-place)

### 📊 **Core Features**

- **Real-time OEE Scoring** — Availability × Performance × Quality per device
- **Multi-device Dashboard** — Single pane of glass across 15–10,000 devices (flat rate, no per-device fees)
- **Floor Plan Editor** — Drag-and-drop device placement with live status overlay
- **Offline Licensing** — Ed25519-signed keys work without internet; optional auto-renewal via `MEMAR_LICENSE_HEARTBEAT_URL`
- **Role-Based Access Control** — Admin, Operator, Viewer roles with JWT auth
- **Notification Hub** — Telegram, Slack, Discord, ntfy, Mattermost, Matrix, generic webhooks
- **Bidirectional Messaging** — Query fleet status, acknowledge alerts from chat
- **Audit Log** — Complete action history (who, what, when) for compliance
- **Custom Branding** — White-label logos, themes, and domain configuration
- **SSO / OIDC (Beta)** — LDAP and OIDC auth-code flow implemented; test in staging before production

### 🔐 **Security & Compliance**

- **No required cloud service — machine data stays local; billing and identity data reach Stripe or your identity provider only if you enable them
- **Air-Gap Deployments** — Offline mode for regulated environments (defense, pharma, financial)
- **TLS Where Supported** — Bambu Lab's MQTT connection is TLS by default; Moonraker/OctoPrint/most LAN adapters poll over plain HTTP unless you put them behind your own reverse proxy — MEMAR doesn't enforce TLS on device-facing traffic
- **Secrets Management** — Environment-based config, no hardcoded keys
- **Audit Trail** — Tamper-evident action log: each entry is hash-chained to the one before it, and `GET /api/admin/audit/verify` reports the first altered or removed entry. Entries written before the chain was introduced are marked unchained, not tampered. The chain does not stop someone with database access from rewriting the whole chain; compare the chain head with a copy kept elsewhere for that.

### 📦 **Deployment Options**

- **Docker Compose** (recommended for most; see INSTALL.md)
- **Bare Metal** — systemd services + manual setup
- **Development Mode** — Hot-reload, debug logging, fake SIM devices

## Breaking Changes (from v0.9.x)

**None.** License key format, API endpoints, and database schema are compatible. Simply deploy v1.0.0 over your existing instance.

## Upgrading

```bash
git pull origin main
docker compose pull
docker compose up -d
```

If using bare-metal systemd, restart the service:
```bash
sudo systemctl restart memar
```

Database migrations run automatically on startup.

## Known Limitations & Future Work

### Beta Features (test in staging first)
- **SSO / OIDC:** Full auth-code flow implemented; test in staging before production
- **Modbus Adapter:** Registered but telemetry stubs only; full implementation TBD

### Not Yet Implemented
- Kubernetes support (no Helm charts exist yet; planned, not started)
- Mobile app (web layout is responsive; formal mobile/accessibility QA pass has not been run yet — see Testing & Quality Metrics; native builds TBD)
- Predictive maintenance (historical data collected, ML pipeline queued for Q3 2026)

### Intentional Non-Goals
- Cloud SaaS variant (we're self-hosted, period)
- Per-device licensing (flat-rate only; no meter taxation)
- Proprietary adapter ecosystem (all adapters AGPL-3.0, no closed-source plugins)

## Getting Started

**5-Minute Quickstart:**
```bash
git clone https://github.com/stratum-industries-foss/memar
cd memar
cp .env.example .env
# Required: generate a JWT secret — the app refuses to start without one
echo "MEMAR_JWT_SECRET=$(openssl rand -hex 32)" >> .env
docker compose up -d
# Default login is admin/admin — the app forces a password change on first login (server-enforced)
# Open http://localhost:8000
```

See [INSTALL.md](../INSTALL.md) for production setup, reverse proxy config, and SSL.
